# Sistema de Cadastro de Clientes — V1.0.0

API REST desenvolvida com Node.js, Express e MariaDB,
utilizando SQL puro, MVC e injeção de dependência.

## Status

🟢 V1.0.0 — CRUD em desenvolvimento

## Tecnologias Ultilizadas
- Node.js
- Express
- MariaDB
- mysql2
- Dotenv
- Nodemon

## Instalação
Como o GitBash abre o comando a baixo, isso fará com que o npm instale as dependências e configurações contidas no package.json.

```
npm install
```
---
## Como executar
Em seu terminal do gitbash execute o comando a baixo
```
npm run dev
```
